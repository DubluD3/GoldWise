# GoldWise

GoldWise is a planned **free, open-source, local-first, read-only economic and profession advisor** for World of Warcraft: Forever.

> **Status: planning / API discovery.** No gameplay or Auction House integration has been validated against the live client yet. This repository must never describe proposed behavior as implemented.

## Principles
1. Observational/advisory only: **no automated purchase, posting, cancelling, bidding, movement or input simulation**.
2. Never invent Blizzard API signatures, game mechanics, profession data or market prices. Unverified claims are explicitly `UNVERIFIED`.
3. Work story-by-story with evidence, tests, and acceptance criteria.
4. All code and features remain free; no ads or donation solicitations in-game.
5. No accounts, telemetry, third-party transmission, or companion process in MVP.

This project is unofficial and is not affiliated with Blizzard Entertainment.
