# Definition of Ready / Definition of Done

## Ready for Codex
- [ ] Story has GW ID, parent feature/capability, dependencies, priority and scope.
- [ ] Acceptance criteria objective and testable.
- [ ] Required API behavior evidenced or split into probe task.
- [ ] Compliance impact clear; no forbidden game actions.
- [ ] Data provenance/licensing and migration concerns identified.
- [ ] Test plan includes failure cases; owner approval for risk.

## Done (implementation)
- [ ] Acceptance criteria demonstrated; proof linked in PR.
- [ ] Tests implemented and actual results recorded (NOT RUN if unavailable).
- [ ] In-game validation performed when required, with build and steps.
- [ ] API_EVIDENCE updated and no hallucinated signature or mechanic.
- [ ] Docs/ADR/privacy/compliance inventories updated.
- [ ] Money/time/market validity, no-double-counting and abstention verified.
- [ ] Performance, storage and migration reviewed.
- [ ] No botting/protected action/network/unapproved third-party code.
- [ ] Owner review and merge approval complete.

## Done (G0 research story)
Sources documented, timestamped, exact unresolved questions and owner action specified; no code required.
